# Camera Path Addon

[tudursvehiclemod](https://github.com/Tuduraw/tudursvehiclemod)のアドオンMODです。Blenderのカメラのように、
地点ごとに**到達tick・XYZ座標・XYZ回転**を指定したキーフレームで、次の2つを正確に動かします。

- **プレイヤーの視点**: 降車キー(スニーク)か最終キーへの到達で終了し、開始前の位置に戻ります(UAVの遠隔操縦の終了と同じ)
- **無人の機体**: 前提MODの機体を、物理演算の代わりに経路どおりに動かします。前提MODのドローン制御と違い、機体の挙動は残らず、速度は時刻で決まります

操作はすべて**カメラ制御ブロック**を介して行います(ドローンセンターと同じ考え方)。キー割り当ては、再生中だけ働く一時停止キー1つです。
1つのブロックが1つの設定なので、複数の経路はブロックを複数置いて管理します。

このMODのコードとドキュメントの作成にはClaude(Anthropic)を使用しています。

## 動作環境

- Minecraft 1.21.11 / Fabric Loader 0.18.2以降 / Fabric API
- tudursvehiclemod 1.1.0以降(`ExternalMotionController`を含むもの)
- サーバーとクライアントの両方に導入してください

## 使い方

1. 前提MODの**ルートブック**で、経路の地点を記録します(ルートブックの記録機能をそのまま使います)
2. **カメラ制御ブロック**を置き、右クリックで編集画面を開きます
3. 「スロット」からルートブックをセットし、「ルートブックから作成」でキーを作ります
   - 航路の各地点(ブロックの中心、ルートブックの座標オフセットを加算)がキーになります
   - 指定した速度(ブロック/秒)で等速になるよう到達tickを決め、向きは進行方向、ロールは航路の値を使います
   - 既存のキーは置き換わります(ボタンを2回押して実行)
4. 編集画面で、到達tick・座標・回転・FOV・補間を調整します。「選択キーで視点確認」で、実際の視点を見ながら調整できます
5. 「視点で再生」で自分の視点を、「機体で再生」で操縦桿に登録した機体を動かします(「開始位置」を選択キーにすると、そのキーから再生します)

ルートブックのデータには何も追加しません。キーと設定はブロックに保存されます。

### スロット

| スロット | 内容 |
|---|---|
| ルートブック | キーを作る元の航路 |
| 操縦桿 | 前提MODのドローン操縦桿。登録された機体が「機体で再生」の対象になります |

## 編集画面

- **タイムライン**: 上部のバーに全キーが並びます。クリックで選択、横にドラッグで到達tickを変更します
- **キーの値**: 到達tick・X・Y・Z・回転X(ピッチ)・回転Y(ヨー)・回転Z(ロール)・FOVを編集し、「適用」(またはEnter)で反映します
  - 角度はMinecraftの表記と同じです(ヨー0=南、ピッチ正=下向き)。F3画面の値をそのまま入力できます
  - 回転はY→X→Zの順に合成します(前提MODの航空機の姿勢と同じ規約)
  - FOVを0にすると、プレイヤー自身の設定を使います
- **補間**(そのキーから次のキーまでの区間に適用。Blenderと同じ考え方)
  - 一定: 次のキーまで値を保持します
  - 線形: 等速の直線です
  - ベジェ: なめらかな曲線です。経路の両端と、値が折り返す点で緩やかに加減速し(Blenderの「自動・クランプ」と同等)、途中のキーは速度の段差なく通過します
- **複製**: 選択したキーを「キーの間隔」tick後に複製します(以降のキーは後ろへずれます)
- **選択以降をずらす**: 選択したキーと以降の全キーの時刻をずらします
- **全体の時間を倍率で**: 全体の長さを倍率で変更します(2なら2倍の時間=半分の速さ)
- **プレビュー**: 表示にすると、このブロックの経路をワールドに表示します(512ブロック以内。ブロックごとに切り替え)
  - 経路線は、その区間で必要になるチャンク数/秒の目安で色分けします(緑: 余裕あり、黄: 注意、赤: 追いつかない可能性)
  - 各キーに番号・到達tick・視線方向の矢印・上方向(ロール)の線を表示します。編集中のキーは大きく表示します
- **停止**: このブロックから開始した再生をすべて止めます
- **一時停止/再開**: このブロックから開始した再生をすべて一時停止します。すべて一時停止中なら再開します
- **開始位置**: 最初のキー/選択キー。「視点で再生」「機体で再生」の開始位置です。ループ再生では、2周目以降は最初のキーから始まります

### 視点確認

「選択キーで視点確認」を押すと、自分の視点が経路上の選択キーの位置・角度・FOVで止まり、編集画面が左側の細いパネルに変わります。パネル以外の部分が、そのキーで実際に映る景色です。

- 遠くのキーでも、サーバーがその地点のチャンクを送るので実際の景色を確認できます
- 別のキーを選ぶと視点がそのキーへ移り、値を変えるとすぐに反映されます
- 各値の「-」「+」(またはフィールド上でマウスホイール)で、「刻み」に応じて増減します

| 刻み | 座標 | 角度 | tick | FOV |
|---|---|---|---|---|
| 細 | 0.1 | 1° | 1 | 1 |
| 中 | 1 | 5° | 5 | 5 |
| 粗 | 10 | 15° | 20 | 10 |

- **全画面で確認**: パネルを隠して画面全体の構図を見ます。クリックかキー入力でパネルに戻ります
- **ここから再生**: 選択キーからそのまま再生を続けます(終了すると、視点確認を始めた位置に戻ります)
- **視点確認を終了**(またはEsc): 視点確認を始めた位置に戻ります
- 視点確認中は、スロットと設定画面は使えません(ブロックの近くに戻ってから操作してください)

### 設定画面

| 項目 | 内容 |
|---|---|
| 設定名 | 画面やプレビューに表示する名前。金床で名前を付けたブロックを置くと、その名前が入ります |
| 回転補間 | オイラー: 角度ごとに補間します。2キー間で180°を超える回転や、ヨー0→720のような回転も可能です。クォータニオン: 姿勢全体を最短経路で補間します。真上・真下付近やロール中のピッチでも乱れませんが、2キー間の回転は180°以内です |
| 機体の終了時 | 最終位置で保持(停止するまで)/通常の挙動に戻す |
| ループ再生 | 最終キーの後、最初から繰り返します |
| レッドストーンで機体再生 | ブロックへの信号の立ち上がりで「機体で再生」を開始します |
| ダミー(座席) | 機体再生中、選んだ座席(P=操縦席、2〜8)が空いていればダミーパイロットを座らせます。**表示のみ**で、攻撃などの動作はしません。照準を設定する座席では必要です |
| キーの間隔 | 複製したキーの間隔 |
| 先行読み込み・経路の幅・後方の保持 | 下記「チャンクの読み込み」 |
| 読み込み待ち | 最初のキーで、先行分のチャンクが読み込まれるまで待ってから開始します |
| 経路全体を事前読み込み | 経路全体のチャンクを開始前に読み込み、終了まで保持します |
| 進行方向を優先して送信 | 下記 |
| 全キーを削除 | ボタンを2回押して実行 |

## チャンクの読み込み

再生中は経路上のチャンクを先回りして読み込みます。

- **先行読み込み**: 現在位置から経路に沿ってNチャンク先まで(直線距離ではなく、経路が通る順)
- **経路の幅**: 経路の両側に追加で読み込むチャンク数
- **後方の保持**: 通過後もMチャンク分は保持し、それより後ろを解放します

読み込みには保存されない独自のチケットを使います。`/forceload`と違ってワールドに残らないため、サーバーが途中で停止しても強制読み込みが残ることはありません。無人機体の再生では、機体の現在位置と数tick先のチャンクをエンティティが動く状態に保つため、周囲にプレイヤーがいなくても経路を進みます。

**クライアントへの送信には描画距離の制約があります。** クライアントが保持できるのは描画距離の範囲内だけなので、それより先を送っておくことはできません。そのため、送信順を「近い順」から「経路の前方の点を中心とした順」に変えています(進行方向を優先して送信)。追いつくかどうかの目安はプレビューの色分けで確認できます。

## 機体の操作(パーツ・ライト・スロットル・照準・武装)

機体再生中、キーフレームごとに機体の操作を設定できます。**乗員がいなくても**、機体のキー操作と同じ動作を機体に直接行います。前提MODの無人機能(ドローン・火力支援センター・Carrier)と同じ処理を使い、前提MODへの変更はありません。

編集画面でキーを選び、「操作」を押します(1つのキーに最大16個)。画面上部のタブで、**機体**(パイロットの操作)と**座席ごと**(その座席の照準と武装)を切り替えます。

### 機体タブ

| 操作 | 設定 | 種類 |
|---|---|---|
| 脚 | 出す/格納 | 状態 |
| ハッチ・キャノピー | 開く/閉じる(ハッチキーと同じく両方) | 状態 |
| 主翼 | 展開/折りたたみ(速度による制限なし) | 状態 |
| サーチライト・航行灯 | 点灯/消灯 | 状態 |
| VTOLモード | 垂直(ヘリ)/水平(航空機)。機体が傾いているなどで切り替えられないときは、切り替えられるまで繰り返します | 状態 |
| 武装の選択 | 武装番号(ウェポンベイなど、選択に連動するパーツが動きます) | 状態 |
| フレア | そのキーで1回 | 動作 |
| スロットル | -1〜1。プロペラ・ローターなどの回転パーツの速さ(0で停止、1で最大)と、エンジン音・HUDのスロットル | 連続値 |
| 左右入力 | -1(左)〜1(右)。ステアリング・操舵輪などのパーツ | 連続値 |

### 座席タブ(操縦席・座席2・…)

| 操作 | 設定 | 種類 |
|---|---|---|
| 照準 | ヨー(機体に対する相対角度。0=正面、正=右回り)、ピッチ(正=下向き。Minecraftの表記と同じ)。この座席の砲塔・武装がこの向きを狙います | 連続値 |
| 武装の発射 | 武装番号(この座席の武装から選択)。「1回」はそのキーで1回、「撃ち続ける」は次のキーまで毎tick発射を試みます(発射間隔・弾数・過熱は武装の設定どおり) | 動作 |

- **照準には、その座席にダミーパイロットが必要です**(設定画面の「ダミー」で座席を選びます)。前提MODでは搭乗者のいない座席の砲塔は動かないためです。照準を設定していない座席は、正面(武装の既定の向き)を狙います
- 座席タブは、操縦桿に登録した機体の座席数だけ表示されます(機体が読み込まれていないときは8座席分)

### 値の変わり方

- **状態**: 指定したキーから、後のキーで変えるまでその状態を保ちます
- **連続値**(スロットル・左右入力・照準): 次に同じ操作(照準は同じ座席)を設定したキーまで直線的に変化し、最後のキーの後は保持します。最初に設定したキーより前は、機体自身の値のままです。サーバーと各クライアントが同じ経路から計算するので、砲塔や車輪もなめらかに動きます
- どのキーから再生しても、ループしても、タイムラインどおりの状態・値になります

### その他

- 武装番号の横には、操縦桿に登録された機体の武装名を表示します
- 操作のあるキーは、タイムラインのマークの下に黄色い印が付きます
- 機体にないもの(脚のない機体の脚など)は無視されます
- 一時停止中は発射しません(状態・値は保ちます)
- スロットルと左右入力はパーツの動きのためのもので、機体の移動は経路が決めます

## 一時停止キー

再生中に**一時停止キー**(初期値: スペース)を押すと、その場で止まります。もう一度押すと再開します。

- 視点再生中は自分の視点を、機体再生中の機体に乗っている場合はその機体を止めます(機体は、再生を開始した人か、ブロックから再生できる人のみ)
- 再生中にしか働かないため、ジャンプキーと同じキーでも問題ありません(操作設定では重複として赤く表示されます)。ジャンプキーとは別の割り当てなので、「操作設定」の「Camera Path Addon」で個別に変更できます
- 一時停止中は停止キー(スニーク)でそのまま終了できます

## 再生中の挙動

- 視点再生中は、HUDと手を隠し(設定で無効化可)、視点の揺れを止めます。プレイヤーは周囲から見えません
- 視点再生中はダメージを受けません。ログアウト時やサーバー停止時は、保存前に開始位置へ戻します
- 機体再生中、その機体は衝突判定なしで経路を進みます。破壊されると再生を終了します
- 機体に乗ったまま機体再生をすると、搭乗者視点で撮影できます
- 機体再生の対象は、読み込まれている(誰かの近くにある)機体です
- ブロックを壊すと、そのブロックから開始した再生は止まります(ルートブックと操縦桿はドロップします。キーと設定は失われます)

## コマンド(権限レベル2)

| コマンド | 内容 |
|---|---|
| `/camerapath play <ブロック座標> camera <プレイヤー>` | そのブロックの経路で視点再生 |
| `/camerapath play <ブロック座標> vehicle [<エンティティ>]` | 機体再生(省略時は操縦桿の機体) |
| `/camerapath stop [<ブロック座標>]` | そのブロックの再生を停止(省略で全て) |
| `/camerapath pause <ブロック座標>` | そのブロックの再生を一時停止(すべて一時停止中なら再開) |
| `/camerapath list` | 実行中の再生 |

1つのコマンドや同じtickの関数で開始した再生は同時に進むので、複数のブロックの経路(視点と機体)を同期させて撮影できます。

## 設定ファイル

`config/camerapathaddon-server.json`

| キー | 既定値 | 内容 |
|---|---|---|
| `playbackPermission` | `"restricted"` | ブロックから再生できる人。`restricted`: クリエイティブ・スペクテイター・OP(レベル2以上)・シングルプレイ/LANのホスト。`everyone`: 全員 |
| `maxLoadedChunksPerPlayback` | 4096 | 1つの再生が読み込むチャンク数の上限 |
| `prepareTimeoutSeconds` | 30 | 読み込み待ちの上限(秒)。超えると開始します |

`config/camerapathaddon-client.json`

| キー | 既定値 | 内容 |
|---|---|---|
| `hideHudDuringPlayback` | true | 視点再生中にHUDと手を隠す |
| `disableBobbingDuringPlayback` | true | 視点再生中に視点の揺れを止める |
| `warnChunksPerSecond` | 200 | プレビューの色分けの基準(チャンク/秒) |

## ビルド

前提MODのディレクトリで`./gradlew publishToMavenLocal`を実行してから、このディレクトリで`./gradlew build`を実行します。
